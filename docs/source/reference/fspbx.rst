FS PBX
******

**Official site:** https://www.fspbx.com/

FS PBX is a PBX platform that began as a FusionPBX fork. It has since
evolved into a separate product with its own user interface,
performance improvements, and additional features while still being
built on top of FreeSWITCH.

FS PBX is open source with paid versions available. It retains the
reliability of FreeSWITCH and the familiarity of FusionPBX-style
workflows, but adds a faster admin interface, stronger multi-tenancy
and white-label support, and more functionality out of the box.

ictVoIP Billing v1.5.0 and later supports FS PBX as a first-class PBX
backend through a dedicated WHMCS server module and Client Services
integration.

FS PBX vs FusionPBX
===================

FS PBX and FusionPBX share a common FreeSWITCH foundation, but FS PBX
is positioned as a more modern, actively developed alternative:

* **Modern User Experience** — Redesigned interface intended to reduce
  the time spent on common admin tasks.
* **Improved Performance** — Faster page loads and more responsive
  tenant management.
* **Enhanced Security** — Additional hardening and access controls
  compared to the upstream fork.
* **More Functionality Out-of-the-Box** — Features that otherwise
  require custom FusionPBX configuration are included by default.
* **Better Multi-Tenancy & White-Label Support** — Built for hosting
  providers that need isolated tenants and branded deployments.
* **Active Development & Community** — Regular releases and a
  commercial support option.

If you are currently using FusionPBX or evaluating open-source PBX
systems, FS PBX can be a compelling upgrade because you keep the
reliability of FreeSWITCH while gaining a faster, easier, and more
powerful management platform.
