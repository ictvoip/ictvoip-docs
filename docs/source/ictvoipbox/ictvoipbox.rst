************
ictVoIP Box
************

.. image:: ../_static/images/admin/ictvoipbox_mainv3.png
   :width: 800px
   :align: center
   :alt: ictVoIP Box main view

The ictVoIP Box addon is a WHMCS addon module that provides client-facing FusionPBX product ordering with backend admin provisioning workflows.

The sections below cover installing and configuring the addon, setting up providers and product mappings, the client checkout experience, provisioning workflows, queue management, troubleshooting, and ongoing maintenance.
